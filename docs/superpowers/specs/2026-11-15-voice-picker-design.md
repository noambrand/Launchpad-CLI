# Voice picker: 10 new ElevenLabs voices, Adam by default

*2026-11-15. Noam's request and choices; branch `feat/voice-picker`.*

## Intent

Noam asked for the voice alerts in a woman's voice, made in his ElevenLabs account, with the same
text and the same triggers as today, and a picker to choose the voice. He listened to samples and
kept 10 American voices. He set the defaults: **Adam** for anyone who has not picked a voice,
**Bella** as the woman's voice.

## Goals

- Ship 10 new voices, each with all 10 lines (Regular and Funny packs × done, error, permission,
  waiting, save), in the current clip format: mono, 16-bit, 44.1 kHz WAV, each clip as loud as the
  matching clip of today's voice.
- A **Voice** row in the picker's Sound alerts section: Male / Female, plus a list of that
  gender's voices, plus Preview.
- Adam plays when `config.json` has no `voice` (new installs and upgrades alike).
- Every agent (Claude, Codex, Copilot, Antigravity) uses the chosen voice. They all go through
  `play.js` already, so no hook changes.

## Non-goals

- No change to which events fire which alert, to the text, or to the hooks.
- No live text-to-speech at alert time (no key, network or delay for users).
- The website's demo sounds stay as they are.

## Anti-goals

- An alert must never go silent because a voice or clip is missing.
- The picker's signed exe must not need a rebuild: the picker only uses bridge calls it already
  has (`ReadFile`, `FileExists`, `Run`).

## Approaches considered

1. **Male / Female buttons only** (the first design): one woman, one man. Dropped: Noam kept
   10 voices.
2. **One flat dropdown of 11 voices**: works, but loses the Male / Female choice Noam first asked
   for and his per-gender defaults.
3. **Male / Female plus a per-gender list (chosen)**: keeps his first request, holds all 10
   voices, and gives each gender its default (Adam, Bella).

## Design

**Files.** `source/sounds/voices/<id>/regular/*.wav` and `.../funny/*.wav` for the 10 new
voices. Today's clips stay in `source/sounds/regular/` and `funny/` (id `original`), so nothing
that points at them breaks. `source/sounds/voices/voices.json` lists the voices (id, label,
gender, description, ElevenLabs id, settings) and the defaults
(`"default": "adam"`, `"default_female": "bella"`).

**Setting.** `config.json` gets `"voice": "<id>"`. The shipped `config.json` does not set it,
so "no pick" means the default from `voices.json` (Adam), falling back to `adam` in code if
`voices.json` can't be read.

**play.js resolve order** for alert `name` in pack `mode` with voice `v`:
`voices/<v>/<mode>/<name>.wav` → `<mode>/<name>.wav` (Original) → `regular/<name>.wav` →
`<name>.wav`. `v = original` skips the first step. The id is sanitized to `[a-z0-9_-]`, so a
bad value can't leave the folder.

**voice.js.** `voice <id>` sets the voice (only ids in `voices.json` or `original`), `voices`
lists them with the current one marked, `choose` asks for a number from that list, `status`
shows the voice. One new launcher pair, **Choose Voice** (`.cmd`, `.command`), runs `choose`.
Test Sounds plays the selected voice (it already goes through `play.js`).

**Picker** (`folder-picker.hta` only; `folder-picker.html` is regenerated by
`picker-app/build-picker.js`). New row under "Voice pack":
`Voice: (•) Male ( ) Female ▶ Preview`, and under it one chip per voice of that gender, its
default first. Chips, not a dropdown: HTA's `<select>` `onchange` is unreliable, so profiles
and models already use chips (`folder-picker.hta`, `populateProfileChips`). Clicking the other
gender selects its default (Adam, Bella); clicking the gender already shown keeps the voice
picked in it. A chip saves `voice` at once (same "✓ saved" flash). Preview plays the `permission` clip of the
selected voice and pack through `play.vbs` (hidden window). If `voices.json` is missing the row
shows Original only. Other keys in `config.json` survive the write, as today.

**Installer and Mac.** Nothing to change: NSIS uses `File /r "source\sounds\*.*"`, the Mac
workflows `cp -R source/sounds`, and `configure-sound-hooks.js` copies folders recursively and
keeps the user's `config.json`. Size: Windows installer about 1.7 MB → 11 MB, Mac package
about 1 MB → 10 MB.

**Tests.** `play.js` resolution (each voice, missing clip, missing voice, bad id, Original,
no `voice` → Adam); `voice.js voice/voices`; every voice in `voices.json` has all 10 clips in
the right format; picker row (lists, gender switch picks the default, save keeps other keys,
missing `voices.json`); picker window still fits (`UT_Picker_WindowFit`).

**Docs.** `source/sounds/README.md`, `README.md`, `docs/CHANGELOG.md` `[Unreleased]`,
`HANDOFF.md`.
